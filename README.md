# 🌐 Celoroční projekt: Můj web

Celý rok budeš stavět **jeden vlastní web**. Začneš čistým HTML a s každým novým tématem ho vylepšíš: přidáš obrázky, styly, rozložení stránky a nakonec i JavaScript. Na konci roku uvidíš, jak se tvůj web proměnil od první verze až po finální.

Web budeš ukládat do **Gitu** a zveřejníš ho přes **GitHub Pages**, takže bude mít vlastní adresu, kterou můžeš komukoli poslat.

---

## 🎯 Vyber si téma

Vyber si **jedno** ze dvou zadání. Obě mají stejné milníky i požadavky, liší se jen obsahem.

### A) Fiktivní podnik
Vymysli si vlastní kavárnu, bistro, obchod nebo firmu: název, zaměření, příběh.

Co může web obsahovat:
- úvod: co podnik nabízí, otevírací doba, adresa
- nabídka / menu / ceník
- o nás: tým, historie
- kontakt (později rezervační formulář)

### B) Fanouškovský web
Web o čemkoli, co tě baví: hra, film, seriál, kniha, sport, kapela, koníček…

Co může web obsahovat:
- úvod: o čem téma je, základní informace
- postavy / členové / hráči
- svět / místa / díly / alba
- historie, časová osa, zajímavosti

> Téma si vyber pořádně, budeš s ním pracovat celý rok. Změna tématu je možná jen po domluvě s vyučujícím.

## 🧩 Jak vypadá každý milník

Každý milník má tři části:

| Část | Povinná? | Co to je |
|---|---|---|
| ✅ **Základ** | ano | Jen to, co jsme probrali v hodině. Kdo splní základ a challenge, má hotovo. |
| 🔍 **Challenge** | ano | Jedna nebo dvě malé věci, které jsme **neprobírali**. Dohledáš si je sám, odkaz na dokumentaci dostaneš. Krátce je vysvětlíš v komentáři v kódu. |

Každé zadání obsahuje **checklist**. Hotové body si odškrtávej přímo v souboru tak, že přepíšeš `- [ ]` na `- [x]` a změnu commitneš.

## 📏 Pravidla

### AI
- Texty můžeš psát s pomocí AI (ChatGPT, Gemini…). **HTML kód ale piš sám.**

### Bezpečnost
- Web je **veřejný**, uvidí ho kdokoli na internetu.
- **Žádné osobní údaje:** adresa, telefon, fotky tebe nebo spolužáků.
- E-mail na webu klidně vymyšlený (`info@mojekavarna.cz`).

### Soubory
- Hlavní stránka se musí jmenovat `index.html`.
- Názvy souborů **bez diakritiky a mezer**: `o-nas.html`, ne `O nás.html`.
- Obrázky **maximálně 5 MB**, video a audio **maximálně 25 MB** na soubor.

## 💾 Jak odevzdávat (Git)

> 🚀 Se zakládáním účtu, repozitáře a GitHub Pages ti pomůže [návod krok za krokem](00-navod-github.md).

1. Pracuj ve svém repozitáři.
2. **Commituj průběžně**, ne všechno najednou večer před termínem. Historie commitů je součástí hodnocení.
3. Piš srozumitelné commit zprávy:
   - ✅ `Přidána tabulka s menu`
   - ✅ `Opravena navigace na stránce kontakt`
   - ❌ `update`, `asdf`, `hotovo`
4. Na konci milníku označ verzi tagem (`v1`, `v2`…). Postup je vždy v zadání milníku.
5. Pushni změny na GitHub. Tvůj web pak běží na GitHub Pages.
